Lis state/trade_history.json.
Identifie les trades du jour (date = aujourd'hui UTC).
daily_pnl = sum(pnl_usdc pour trades fermés aujourd'hui)
Si daily_pnl < -(portfolio_total × daily_loss_limit_pct) :
→ tg("⛔ Daily loss limit atteinte. Trading pausé pour aujourd'hui.")
→ ARRÊTE.

Vérifie les trades "open" avec sl_order_txid actif :
Pour chaque trade open dans trade_history.json avec un champ sl_order_txid :
  kraken query-orders {sl_order_txid} -o json
  Si status == "closed" :
    → Stop-loss déclenché. exit_price = float(cost) / float(vol_exec)
    → exit_fee_usdc = float(fee) (champ "fee" présent dans la même réponse query-orders, en USDC)
    → entry_fee_usdc = trade.get("entry_fee_usdc", 0) ou 0 (déjà stocké à l'entrée par phase5_execution.py)
    → fees_usdc = entry_fee_usdc + exit_fee_usdc
    → pnl_gross_usdc = (exit_price - entry_price) × quantity
    → pnl_usdc = pnl_gross_usdc - fees_usdc   # PnL NET, frais Kraken déduits (#382)
    → pnl_gross_pct = (exit_price - entry_price) / entry_price × 100   # ancien calcul brut, conservé
    → pnl_pct = pnl_usdc / (entry_price × quantity) × 100   # PnL NET en %, même signe que pnl_usdc (#382)
    → Met à jour trade_history.json : status="closed", exit_price, entry_fee_usdc, exit_fee_usdc,
       fees_usdc, pnl_gross_usdc, pnl_usdc, pnl_gross_pct, pnl_pct, exit_date (UTC), close_reason="sl_hit",
       cycle_id=None
    → Si pnl_usdc > 0 : tg("✅ SL déclenché (profit) : {COIN} +{pnl_usdc:.2f} USDC (+{pnl_pct:.1f}%)")
    → Sinon : tg("🛑 Stop touché : {COIN} {pnl_usdc:.2f} USDC ({pnl_pct:.1f}%)")
